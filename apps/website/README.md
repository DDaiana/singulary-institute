# Singulary Research Website

A launch-ready Vite + React website for the Singulary Research section of the SAR ecosystem.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Structure

- `src/main.jsx` — page structure and content
- `src/styles.css` — full visual system
- `public/assets/singulary-symbol.png` — custom Singulary symbol used in header/footer and orbital visuals

## Pages

The site uses hash routes:

- `/#research`
- `/#publications`
- `/#research-areas`
- `/#methodology`
- `/#archive`
- `/#about`
