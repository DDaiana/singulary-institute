# Public Export Workflow

## Workflow

```text
Private Operating Brain
  ↓
Research Output Approved
  ↓
Publication Clearance Review
  ↓
Public Export Package
  ↓
Codex Execution OS
  ↓
Public Repository
  ↓
Website
```

## Rule

GitHub receives exports. GitHub does not contain the full operating system.

## Export Package Requirements

Every public export package must identify:

- public assets to commit
- private assets to keep local
- internal assets requiring clearance
- publication clearance status
- research mode
- evidence status
- public-safe wording

## Codex Boundary

Codex implements approved public export packages only.

Codex must not commit local-only private operating brain material.
