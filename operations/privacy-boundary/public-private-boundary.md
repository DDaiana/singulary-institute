# Public / Private Boundary

## Public GitHub Layer

GitHub may expose:

- public website
- safe content registry
- public research areas
- public programme summaries
- public project descriptions
- public publication status
- public governance principles
- public methodology summaries
- public-safe archive entries

## Local-Only Private Layer

GitHub must not expose:

- private strategy notes
- sensitive funding details
- rejected grant details unless intentionally disclosed
- personal financial information
- internal reasoning logs
- unpublished strategic decisions
- private prompts if considered sensitive
- draft claims not ready for public view
- source notes not cleared for publication
- operational brain details beyond public-safe summaries

## Rule

Codex may only commit public-safe outputs unless explicitly instructed otherwise and clearance is documented.
