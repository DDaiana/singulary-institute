# Public-Safe Content Policy

## Allowed in GitHub

- public programme summaries
- public project descriptions
- published or safe draft outputs
- general methodology
- public-safe governance principles
- website content
- content registry entries
- public archive entries

## Not Allowed in GitHub

- private strategy reasoning
- private funding notes
- rejected grant details unless intentionally disclosed
- personal financial information
- private prompts
- personal data
- confidential source notes
- non-public research notes
- unverified claims presented as fact
- internal decision logs containing sensitive details

## Standard

If content is not clearly public-safe, keep it local-only until publication clearance is complete.
