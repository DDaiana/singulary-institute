# Private Operating Brain Policy

The local project folder may contain a private operating layer that is not committed to GitHub.

Recommended local-only folder:

`_private/`

This folder may contain:

- private ChatGPT research sessions
- internal strategic reasoning
- private grant notes
- sensitive opportunity assessments
- non-public source notes
- unpublished draft reasoning
- personal execution notes
- rejected funding analysis
- raw evidence notes not cleared for publication

This folder must be excluded from Git.

## Rule

The private operating brain is local-only. It is not part of the public GitHub output layer.

## Source Of Truth

The Private Operating Brain is the institutional source of truth.

GitHub is a public delivery layer that receives cleared exports only.
