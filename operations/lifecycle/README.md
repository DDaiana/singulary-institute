# Lifecycle Management

The lifecycle layer governs maturity, stage, and next action across Singulary Institute.

It applies to:

- Research Areas
- Programmes
- Projects / Research in Motion
- Publications / Outputs
- Grants
- Strategic Initiatives

This layer does not replace the content registry or the existing operations governance system. It adds status and stage controls to the existing institutional model.

## Governance Rule

Every governed item must know:

- what it is
- where it belongs
- how mature it is
- what stage it is in
- what happens next

## Required Controls

- Status
- Lifecycle Stage
- Last Updated
- Next Required Action
- Owner
- Related Programme
- Related Research Area

## Source of Truth

The content registry remains the source of truth for research area, programme, project, and publication relationships. Operations registries are governance control indexes that reference the same canonical objects.
