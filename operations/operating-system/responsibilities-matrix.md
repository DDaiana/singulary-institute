# Responsibilities Matrix

| Task | Owner | Notes |
| --- | --- | --- |
| Research Question | Research OS | Research Director defines and tests strategic value. |
| Research Mode Selection | Research OS | Research Director determines Interpretation of Existing Evidence, Hybrid Research Mode, or Generation of New Evidence before research begins. |
| Evidence Identification | Research OS | Evidence Collector assists in identifying potentially relevant traceable sources. |
| Evidence Organization | Research OS | Evidence Collector organizes source material and maintains evidence registries. |
| Evidence Extraction | Research OS | Evidence Collector extracts observations from documented sources only. |
| Evidence Synthesis | Research OS | Evidence Synthesizer compares sources, contradictions, limitations, and themes. |
| Programme Placement | Research OS | Programme Architect determines placement. |
| Research Area Placement | Research OS | Programme Architect determines area fit. |
| Publication Classification | Research OS | Editorial Director classifies type, editorial state, and trust requirements. |
| Grant Fit | Research OS | Grant Strategist assesses fit and deliverables. |
| Institutional Audit | Research OS | Institutional Auditor checks duplication, fragmentation, and coherence. |
| Implementation Package | Research OS | Generated after strategic, programme, grant, editorial, and audit review. |
| Repository Update | Execution OS | Repository Engineer implements folder and file changes. |
| Website Update | Execution OS | Website Engineer implements routes and page content. |
| Registry Update | Execution OS | Registry Engineer updates content, programme, project, publication, lifecycle, and evidence registries. |
| Documentation Update | Execution OS | Documentation Engineer creates Markdown records, audits, and logs. |
| Build Verification | Execution OS | Codex runs build and reports status. |

## Boundary

The Research OS decides. The Execution OS implements.

ChatGPT may assist in identifying, organizing, reviewing, extracting, and synthesizing evidence from traceable sources provided through research workflows. It may not generate evidence, fabricate observations, or claim findings without documented sources.
