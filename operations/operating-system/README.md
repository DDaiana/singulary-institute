# Operating System

The Singulary operating system defines how work moves from strategic research judgement to repository execution.

It completes the institutional model:

You

-> ChatGPT Research OS

-> Codex Execution OS

-> Singulary Institute

## Operating Principle

The Research OS decides research direction, evidence handling, programme placement, publication classification, and institutional fit.

The Execution OS implements approved packages in the repository.

Codex implements. Codex does not decide strategic direction, programme placement, research validity, or evidence status.
