# Codex Execution OS

The Codex Execution OS is the implementation layer.

Codex implements approved implementation packages. Codex does not decide strategic direction, programme placement, research validity, evidence status, or publication trust level.

## Roles

### Repository Engineer

Responsibilities:

- repository structure
- folder creation
- registry updates
- file organization

### Website Engineer

Responsibilities:

- routes
- content integration
- page updates
- build validation

### Registry Engineer

Responsibilities:

- content registries
- programme registries
- project registries
- publication registries
- lifecycle fields
- evidence fields

### Documentation Engineer

Responsibilities:

- Markdown generation
- governance records
- audits
- implementation package records
- decision log entries

## Codex Responsibilities

Codex must:

- implement approved packages
- preserve repository structure
- avoid duplicate systems
- run build and verification
- update files intentionally
- report changes and residual risks

Codex must not:

- determine research validity
- invent sources
- fabricate findings
- decide programme fit without Research OS approval
- classify publications as evidence-based without documented evidence review
