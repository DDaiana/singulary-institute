# Project Registry

This registry tracks lifecycle status for projects and research in motion.

It does not replace `content/content-registry.json`; it governs maturity, stage, ownership, dependencies, and next action.

Required fields:

- Project Name
- Research Area
- Programme
- Status
- Lifecycle Stage
- Research Type
- Evidence Level
- Source Count
- Review Status
- Trust Level
- Last Updated
- Next Required Action
- Expected Outputs
- Dependencies
