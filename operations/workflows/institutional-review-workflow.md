# Institutional Review Workflow

## Input

Repository state.

## Sequence

1. Audit website routes and public labels.
2. Audit content registry relationships.
3. Audit research infrastructure folders.
4. Audit publication and archive records.
5. Audit deployment workflow.
6. Identify duplication, fragmentation, dead structures, and missing governance.
7. Produce recommendations and implementation package.

## Output

- health report
- duplication report
- fragmentation report
- recommendations

## Exit Criteria

The review is complete when every recommendation is assigned to a role, workflow, or implementation package.
