# Programme Creation Workflow

## Input

Approved Strategic Assessment.

## Sequence

1. Confirm the work cannot fit inside an existing programme.
2. Define research area alignment.
3. Define programme purpose and boundaries.
4. Define initial projects.
5. Define methodology requirements.
6. Define publication and archive implications.
7. Produce Codex Implementation Package.

## Output

- Programme Blueprint
- Project Structure
- Research Architecture

## Exit Criteria

Programme creation is approved only when duplication and overlap risks are explicitly resolved.
