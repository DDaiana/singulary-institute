# Publication Workflow

## Input

Research output.

## Sequence

1. Confirm the output belongs to a project.
2. Confirm the project belongs to a programme.
3. Confirm the programme maps to one or more research areas.
4. Editorial Director reviews status, claims, structure, and archive readiness.
5. Institutional Auditor checks publication fragmentation.
6. Codex Implementation Package defines content registry and website changes.

## Output

- publication plan
- editorial review
- archive placement

## Exit Criteria

No output is published without project, programme, research area, status, and archive implications.
