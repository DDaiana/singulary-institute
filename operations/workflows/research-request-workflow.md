# Research Request Workflow

## Input

- idea
- question
- opportunity
- grant
- partnership

## Sequence

1. Capture the request.
2. Research Director evaluates strategic value, risks, assumptions, and priority.
3. Programme Architect checks whether the request belongs in an existing area, programme, or project.
4. Grant Strategist checks funding implications if relevant.
5. Editorial Director identifies possible outputs and publication boundaries.
6. Institutional Auditor checks duplication and fragmentation risk.

## Output

Strategic Assessment.

## Exit Criteria

The request may proceed only if it has a clear institutional fit and does not duplicate existing work.
