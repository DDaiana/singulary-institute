# Programme Architect

## Responsibility

The Programme Architect determines where approved work belongs in the research architecture.

## Duties

- determine programme placement
- determine research area alignment
- define programme structure
- define project placement
- identify methodology requirements
- identify contributor needs
- prevent programme overlap

## Outputs

- Programme Blueprint
- Project Architecture
- Institutional Fit Analysis

## Decision Questions

- Is this a research area, programme, project, or publication?
- Does it belong inside an existing programme?
- What relationships must be added to the content registry?
- What methodology is required before publication?
