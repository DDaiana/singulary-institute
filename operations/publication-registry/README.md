# Publication Registry

This registry tracks lifecycle and editorial state for publication outputs.

It does not replace `content/content-registry.json`; it governs status, editorial state, archive state, and next action.

Required fields:

- Publication Type
- Related Project
- Related Programme
- Research Area
- Status
- Lifecycle Stage
- Research Type
- Research Mode
- Evidence Strategy
- Primary Research Required
- Evidence Generation Required
- Evidence Level
- Source Count
- Review Status
- Trust Level
- Editorial State
- Publication Date
- Archive Status
