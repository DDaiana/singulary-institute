# Interpretation of Existing Evidence Workflow

Research Question

-> ChatGPT Research OS

-> Research Director

-> Evidence Collector

Evidence Collector assists with:

- identify potentially relevant sources
- identify reports
- identify papers
- identify datasets
- organize source material
- extract observations from documented sources

-> Evidence Registry

-> Evidence Synthesizer

Evidence Synthesizer assists with:

- compare documented findings
- identify contradictions
- identify patterns
- generate synthesis from traceable source material

-> Editorial Director

-> Publication Draft

-> Codex Execution OS

Codex Execution OS implements:

- repository updates
- registry updates
- website updates
- archive updates

-> Publication

## Safeguard

This workflow interprets existing evidence. It does not generate new evidence, fabricate findings, or create unsupported factual claims.
