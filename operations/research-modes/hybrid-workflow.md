# Hybrid Research Mode Workflow

Research Question

-> ChatGPT Research OS

Research OS assists with:

- identify sources
- collect reports
- extract evidence from documented sources
- compare findings
- identify contradictions
- build synthesis

-> Supplementary Evidence Plan

Limited original input may be included only if approved:

- interviews
- surveys
- practitioner feedback
- contributor observations

-> Evidence Registry

-> Evidence Synthesis

-> Editorial Review

-> Publication Draft

-> Codex Execution OS

Codex Execution OS implements:

- repository updates
- website updates
- registries
- archive

-> Publication

## Safeguard

Hybrid outputs must distinguish existing evidence synthesis, supplementary original input, interpretation, and limitations.
