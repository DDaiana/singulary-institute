# Funded Interpretive Intelligence Workflow

Research Question

-> Funding / Support Approved

-> Research Mode Review

If no new evidence generation is planned:

-> Interpretation of Existing Evidence

-> ChatGPT Research OS

Research OS assists with:

- identify sources
- collect reports
- extract evidence from documented sources
- compare findings
- identify contradictions
- build synthesis

-> Editorial Review

-> Publication Draft

-> Codex Execution OS

Codex Execution OS implements:

- repository updates
- website updates
- registries
- archive

## Rule

Funding supports capacity. Funding does not automatically change evidence type.
