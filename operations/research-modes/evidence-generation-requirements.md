# Evidence Generation Requirements

No project may be classified as Generation of New Evidence without documenting:

- Research Design
- Evidence Collection Method
- Data Source Plan
- Review Process
- Expected Outputs

## Additional Required Controls

- participant or data governance requirements, if relevant
- ethics or safeguarding requirements, if relevant
- privacy and consent requirements, if relevant
- archive plan
- publication trust classification path

## Repository Rule

If `evidence_generation_required` is true, the project must have an evidence generation approval record before implementation begins.
