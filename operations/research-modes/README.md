# Research Mode Engine

The Research Mode Engine classifies every project into one of two modes:

1. Interpretation of Existing Evidence
2. Generation of New Evidence

The mode determines workflow, evidence requirements, publication requirements, trust classification pathway, and project expectations.

This engine integrates with the existing Governance Layer, Lifecycle Layer, Evidence Layer, registries, Research OS, and Execution OS. It does not create a parallel governance or lifecycle system.

## Required Project Fields

- Research Mode
- Evidence Strategy
- Expected Evidence Sources
- Research Requirements
- Primary Research Required
- Evidence Generation Required
- Trust Classification Path

## Rule

No project may proceed without a research mode decision.
