# Knowledge Asset Framework

The institutional model is:

```text
Project
  ↓
Knowledge Assets
  ↓
Public Outputs
  ↓
Institutional Credibility
  ↓
Grant Support
```

Every private project should be capable of generating reusable assets.

Assets support publications, website content, future grants, fellowships, partnerships, and institutional credibility.

Assets survive even if a funding application is unsuccessful.
