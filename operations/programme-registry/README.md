# Programme Registry

This registry is a lifecycle governance index for programmes.

It does not replace `content/content-registry.json`. The content registry remains the source of truth for website and content relationships. This registry tracks operational maturity, stage, owner, and next action.

Required fields:

- Programme Name
- Status
- Lifecycle Stage
- Research Type
- Research Mode
- Evidence Strategy
- Funding Status
- Funding Visibility
- Primary Research Required
- Evidence Generation Required
- Public Safe
- Publication Clearance
- Evidence Level
- Source Count
- Review Status
- Trust Level
- Last Updated
- Next Required Action
- Owner
- Active Projects
- Published Outputs
- Research Areas
- Future Priorities
